# Triage simulation — specification conformance

Generated by `scripts/triage_simulation.py` over `150` vignettes on the SATS scale.

## How to read these numbers

- **Reference column:** `design_target` — the `intended_tier` each vignette was built to exercise.
- **This is specification conformance, not clinical validity.** No clinician labelled this set, so agreement says the rules land where they were designed to land, not that they match a nurse's judgement.
- **Inter-rater reliability: NOT available.**
  A kappa comparing two raters is deliberately **not** reported: there is a single non-clinician author and no second labeler. The tool-vs-design-target figures below are *not* a substitute for that missing statistic.
  Attempting it returns: *inter-rater kappa needs a clinician label and a second labeler; fixture has clinician_label=False, second_labeler_id=None*

## Provenance note

> intended_tier is the SATS category each vignette was constructed to exercise, assigned by a single non-clinician author. It is a specification-conformance answer key, not a clinician's reference standard. Because there is no clinician label and no second labeler, agreement against it measures whether the rules realise their design intent — not clinical validity — and inter-rater reliability is not computed. Replace intended_tier with reviewed clinician labels (and set second_labeler_id) to produce the tool-vs-clinician kappa the paper's title promises.
